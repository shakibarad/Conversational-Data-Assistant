# AI-Powered Logistics Analytics Assistant

An AI-powered analytics assistant that combines **Text-to-SQL, Retrieval-Augmented Generation (RAG), Python, SQL, and local Large Language Models (LLMs)** to make logistics data easier to explore and understand.

The project enables users to interact with logistics data using natural-language questions and retrieve data-driven insights through AI-assisted analysis.

## Technologies
- Python
- SQL
- Text-to-SQL
- Retrieval-Augmented Generation (RAG)
- Local LLMs

## Project Goal
To explore how Generative AI and LLM-based applications can make data analytics more accessible, interactive, and efficient.
